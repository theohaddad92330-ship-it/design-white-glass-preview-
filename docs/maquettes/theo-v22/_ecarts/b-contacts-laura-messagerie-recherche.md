## Comment lire ce document

- **Source Théo.** Les trois HTML (`Produit_Complet`, `BPCE`, `Onboarding`) sont **identiques au caractère près**, sauf la route d'ouverture par défaut (`#/chat`, `#/accounts/a-bpce`, `#/onboarding/welcome`). L'inventaire vaut donc pour les trois. Il a été fait en **rendant le prototype** (Chromium sans tête, 1440 px) et en lisant le texte et les contrôles de chaque route, puis de chaque modale / panneau ouvert par un clic. Rien n'a été déduit du seul code du prototype (il empile les surcouches V2…V18 : la dernière gagne).
- **Source « existant ».** Le code de `origin/main` : routes, composants de page, libellés français. Les routes `/contacts/imports`, `/contacts/<id>/approach/email|call`, `/mailbox/drafts` **n'existent pas** aujourd'hui (aucune entrée dans `routeTree`) ; l'équivalent existant est donné chaque fois avec son `fichier:ligne`.
- **Identifiants.** `<écran>.R<n>` = REDESSIN, `<écran>.N<n>` = FEATURE NEUVE, `<écran>.A<n>` = ABSENTE CHEZ THÉO (la liste qui part en QCM à Louis). Codes écran : **C1** Répertoire · **C2** Mes listes · **C3** Imports & sources · **C4** Assistant d'import · **C5** Fiche contact · **C6** Approche e-mail / LinkedIn · **C7** Approche appel · **L1** Laura · **M1** Messagerie « À traiter » · **M2** Messagerie « Brouillons / À venir / Historique » · **R1** Recherche (cadrage) · **R2** Recherche (Mes analyses + Vérification).
- Les libellés de Théo sont recopiés tels que rendus. Un libellé entre « » est un libellé affiché.
- Les `*.A<n>` sont écrits **sans nom de composant** dans leur première phrase (geste utilisateur), le `fichier:ligne` vient après, pour le QCM.

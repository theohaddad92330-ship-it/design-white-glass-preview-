Relevé du 15/10/2026 (#3973, décision Louis 05/10/2026 : logos autorisés dans le seul sélecteur « Outils et sources »).

Source : Wikimedia Commons, fichiers sous modèle de domaine public (`PD-textlogo`, `PD-logo`, `PD-shape` : logo non protégeable par le droit d'auteur). **La marque reste la propriété de son titulaire** : le fichier n'autorise que son affichage pour l'outil que l'espace a lui-même branché. Aucun logo n'est chargé à distance. Un outil sans fichier garde son icône.

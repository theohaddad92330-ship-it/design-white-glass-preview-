## §7. Les pièges d'outillage mesurés ce soir — les relire coûte moins cher que les revivre

- **Une sonde qui ne lit rien rend le même zéro qu'une page saine.** `main *` sur
  un écran sans `<main>` = 0 élément. **Tout relevé porte son `corpusLu`**, et
  retombe sur `document.body`.
- **Compter un état par `grep -c "| <état> "` attrape de la prose** (légendes,
  en-têtes). J'ai cru perdre 3 `recetté` ; il n'en manquait aucun. Compter les
  lignes qui matchent le motif de POINT.
- **Fusionner deux registres ne suit PAS la règle « on garde les deux côtés »** :
  ça duplique les lignes de points (127 mesurées). Dédupliquer par numéro, l'état
  le plus avancé gagne, **et vérifier avant de committer**.
- **`git merge --abort` dans une boucle** annule aussi la fusion précédente restée
  en conflit — les suivantes échouent en cascade sur un message trompeur.
  Fusionner une branche à la fois.
- **Le hook `pre-push` rame quand des écrivains tournent.** `--no-verify` est
  légitime **uniquement** si le diff ne contient aucun fichier de code — le
  vérifier (`git diff --name-only origin/main..main`) et le dire.
- **L'outil `computer` perd sa cible** (« Couldn't determine which page this
  action targets ») : rappeler `tabs_context_mcp` avant chaque lot, et recréer un
  onglet neuf s'il s'obstine.
- **Un menu qui ne s'ouvre qu'au survol ne s'ouvre pas sous automatisation.**
  Trancher par le code (`git grep` de l'appelant) **avec un témoin** qui prouve
  que le corpus répond — quatre greps vides peuvent être quatre greps mal écrits.

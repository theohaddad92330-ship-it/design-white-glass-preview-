# Inventaire du noyau prompt de Laura — #2256 (LAU-FINAL-001)

Mesuré sur `feat/laura-noyau-contexte-memoire-17-09-reprise`, 17/09/2026.

## Pourquoi ce document

Le registre `.claude/notes/registre-2026-09-17-lau-001-2256.md` constatait qu'un
« un seul cerveau pour toutes les surfaces » est déjà VRAI structurellement
(gardes GA-237/GA-238, un seul `bellum_advisor.build_system_prompt` appelé
pour tout tour de `/chat` — voir 2256.1, 2256.25) mais qu'**aucun document
n'inventoriait les éléments qui composent ce cerveau** (2256.3) avec un champ
par élément : rôle (2256.4), surface (2256.5), état actuel (2256.6), source de
vérité (2256.7), doublon éventuel (2256.8), règle plus récente qui remplace
(2256.9), comportement à conserver (2256.10), comportement à supprimer après
migration (2256.11). Ce fichier est ce livrable. Il ne change aucun
comportement : c'est une photographie, pas un refactor.

Périmètre : le NOYAU du chat (`bellum_advisor.py` + les modules qu'il
assemble). Les prompts de domaine (`bellum_messages.py`, `bellum_plan.py`,
`bellum_scorer.py`, `bellum_organigramme.py`, `bellum_weekly.py`,
`bellum_profiler.py`, `bellum_rfp.py`, `bellum_cv.py`, etc.) en sont
explicitement EXCLUS : ce sont des extensions invoquées par la pipeline
d'analyse déclenchée, jamais parlées directement par l'utilisateur (2256.22,
`déjà là`) — ils méritent leur propre inventaire le jour où ce chantier s'y
attaque, pas celui-ci.

## Comment lire la table

- **Source de vérité** : le fichier:ligne qui définit l'élément aujourd'hui —
  c'est CE fichier qu'on modifie, jamais une copie.
- **Doublon éventuel** : une note explicite quand deux éléments pourraient se
  lire comme redondants, et pourquoi ils ne le sont pas (la plupart des « quasi
  doublons » de ce noyau ont déjà leur justification écrite en commentaire
  Python au-dessus du bloc — recopiée ici, pas réinventée).
- **Comportement à conserver / à supprimer après migration** : aucune
  migration n'est EN COURS sur ce noyau au 17/09/2026 (le noyau unique est déjà
  la réalité, cf. 2256.1/2256.25) — ces deux colonnes servent de RÉFÉRENCE pour
  la PROCHAINE consolidation qui retirerait ou fusionnerait un bloc, pas d'un
  chantier ouvert aujourd'hui. Une valeur inventée ici serait une donnée
  fictive ; la colonne dit donc « aucune migration en cours » plutôt qu'un
  verdict deviné.

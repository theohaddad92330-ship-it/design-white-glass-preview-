- **Bloc 1 (~60 noms)** : sous-ensemble curé, dominé par des ESN PME / boutiques / mid-market.

## Positionnement / notes

- Le document **ne contient pas de note de positionnement** (pas de CA, effectifs, spécialité,
  région). Toute mention de tier/positionnement ci-dessus est dérivée et indicative.
- Pour l'enrichissement réel (NAF 62.0x, effectifs, région), s'appuyer sur Sirene/Pappers comme
  défini dans `agent_docs/apis.md` — cette liste sert uniquement de **dictionnaire de noms** pour
  la reconnaissance d'entités concurrentes.

## Consommation par les prompts

- **signals (concurrents ESN)** : matcher les noms détectés dans les sources (web, offres d'emploi,
  press) contre ce dictionnaire pour identifier un concurrent ESN déjà implanté sur le compte cible.
- **strategy** : pondérer la menace (Tier 1 major incumbent vs Tier 3 boutique) pour ajuster
  l'angle d'attaque commercial.

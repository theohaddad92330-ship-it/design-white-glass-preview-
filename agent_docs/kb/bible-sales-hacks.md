# Bible Sales — 100 Hacks (distillé)

Source : "LA BIBLE SALES — 100 Hacks" (auteur non-technique, prospection ESN).
Tactiques business actionnables, filtrées pour l'usage ESN/BellumAI. Citations verbatim entre guillemets.

---

## A. Messages d'outreach (copywriting)

- **Premier message LinkedIn = zéro vente, juste du lien contextuel.** Verbatim : « Vu votre rôle chez X, j'avais une question. » / « J'ai vu vos projets sur [X], curieux d'échanger. »
- **Mail = 3 lignes max.** Structure : Ligne 1 = contexte, Ligne 2 = question directe, Ligne 3 = signature pro.
- **Parler comme le client parle** : réutiliser ses mots, sa techno, ses enjeux.
- **Pitch orienté besoin, pas profil.** Verbatim : « Vous travaillez sur [X], je pense pouvoir vous aider dessus. »
- **Adapter le discours au niveau du contact** (Ops / C-Level / Achat) = 3 scripts, 3 logiques.
- **Jamais de PDF dans un premier mail** — préférer le texte brut ou une landing page.
- **Signature mail enrichie** (lien CVs / site / livre d'or / téléphone / entité / service) = crédibilité passive + permet de mapper le périmètre du contact.
- 3 modèles de messages à alterner pour ne pas spammer : **Découverte / Relance / Lien.**
- Messages **vocaux LinkedIn** = peu utilisés, haut taux d'écoute, fort différenciateur.
- Tester / mesurer / itérer : tracker chaque message et son taux de réponse.

## B. Objets de mail & openers (taux d'ouverture)

- **Objets courts qui performent** : « Demande rapide », « Question pour vous » — annoncé +30% d'ouverture.
- **Ouvrir sur un signal observé**, pas sur soi : un projet, un rôle, un AO, un like.
- Ops d'abord, jamais l'acheteur en premier : « Toujours commencer par ceux qui ont mal. »

## C. Séquence & relances (follow-ups)

- **Séquence de relance sur 21 jours** : J+2, J+5, J+12 (puis ~J21). Automatisable (Lemlist / Hubspot).
- **Relancer les prospects "perdus" 6 mois après**, message perso. Verbatim : « Depuis notre dernier échange… »
- **Leads froids = objectifs à 14 jours** pour ne pas laisser mourir le pipe.
- Téléphoner pour **capter un besoin immédiat / une info concrète**, pas pour booker un call.
- **Hack OOO (out-of-office)** : envoyer une séquence pendant les vacances pour récolter les réponses auto (numéros, redirections, backups).

## D. CTA & clôture de RDV

- **Toujours conclure un RDV par** : « Quelles sont les prochaines étapes concrètes ? »
- En call, ouvrir le cross-sell : « Et en dehors de vous, qui dans votre équipe cherche du renfort ? »
- Sur un refus, demander un retour pour apprendre : « Quel critère a bloqué ? »

## E. Qualification de comptes (qualif)

- **1 compte stratégique par semaine, creusé à fond** : objectif 10 contacts ajoutés, 3 infos clés remontées.
- **Organigramme évolutif par compte** : noms, rôles, entités, BU, prestataires.
- **Audit prestataire** du compte : quelles ESN déjà présentes ? quels consultants ? quelles technos ?
- **Identifier les prestataires en fin de mission** = cible replacement / transition directe.
- **Analyse concurrentielle du compte** : qui vend ? sur quelle techno ? à quel TJM ?
- **Identifier les ESN déjà référencées** → proposer la co-traitance pour passer par elles.
- Heuristiques internes : « Un budget chez un client est fait pour être dépensé » ; « Les opérationnels parfois n'aiment pas les achats ».
- **Sources de signaux** : AO publics (BOAMP, TED, AWS), alertes Google « client + appel d'offres + prestation », likes sur offres d'emploi du compte, signatures mail.
- **Prospection inversée via freelances** : contacter les freelances déjà passés chez le client pour collecter l'info interne ; « Tu connais qui dans ce compte ? » = réseau chaud immédiat.
- **CVthèque** : analyser les profils LinkedIn d'anciens employés du compte → technos & missions gérées.

### Checklist GO / NO-GO / WHY (suivi deal)

1. Le candidat a-t-il déjà été présenté ?
2. A-t-il le droit de retourner sur le compte ?
3. Qui est le responsable achat ?
4. Ai-je la grille achat des TJM ?

## F. Objections & pricing

- **Script d'objections type** à préparer : budget, délai, référencements, remote, exclusivité.
- **Registre objections & réponses** centralisé = argumentaire prêt à l'emploi.
- **Reformuler le besoin à l'oral** systématiquement = crédibilité + clarté.
- **Pricing avec ancrage tarifaire fort** : TJM marché + références + succès similaires.
- **Seuil de marge minimum à chaque GO** (ex. 1000€/mois net mini, sinon mission refusée).
- Présenter le consultant comme **levier business**, pas comme ressource : « Il/elle va vous faire gagner… »

## G. Positionnement & preuve sociale

- **Partenaire, jamais fournisseur** : « On travaille avec vous. »
- **Offres différenciantes par techno/métier** (Offre Data, DevOps, Produit) ; packs solution (Squad Data, Task Force DevOps) ; profils en duo (Lead + Confirmé) = upsell rassurant.
- **Preuve sociale réutilisable** : livre d'or (4+ retours consultants), livret « 10 succès récents », REX de missions « sexy », à joindre en propal/mail.
- Documenter tous les gains clients liés aux consultants (livraison, perf, KPI).

## H. Routines & outils (contexte, non-prompt)

- Mapping compte (Notion/Excel), fiche « Plan de Compte » (Gamma), board Miro comptes prioritaires.
- Plan de pénétration compte glissant sur 3 mois avec jalons (ajout, message, call, besoin).
- KPIs hebdo : GO client, nouveaux leads, conversion (pas plus) ; objectif type : 3 RDV / 1 GO / 10 contacts.
- Requête booléenne LinkedIn générée via LLM pour scraper les métiers d'un compte.

> Note : hacks "gris" écartés (faux CV en CVthèque, etc.) — non retenus.

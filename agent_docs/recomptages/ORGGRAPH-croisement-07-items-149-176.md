#### Les défauts trouvés en chemin

1. **Trois documents d'analyse écrits le matin du 30/08 ont été rendus obsolètes par du code mergé le même jour.** `orggraph-inventaire-existant-2026-08-30.md` qualifie le ledger de corrections (item 153) de « CODE MORT » — c'était vrai à l'heure où il a été écrit, faux depuis le commit `382b099cd`/`244209f1e` (même journée, plus tard). `orggraph-contradictions-2026-08-30.md` documente le bandeau de couverture qui « fabrique un chiffre que le contrat refuse » — vrai avant `3f2e18df7` (30/08 11h52), faux après. `orggraph-inventaire-existant-2026-08-30.md` D288 documente le bouton « vérifier ce lien » sans sujet — vrai avant `ce3c8bf7d` (30/08 12h27), faux après. **Aucun de ces trois documents n'était faux au moment où il a été écrit** ; c'est la consigne « revérifier contre le code d'aujourd'hui » qui a payé ici, pas une erreur des documents.
2. **Le bloqueur « jamais recommandé » (168) n'est tenu qu'à l'affichage, pas à la source.** L'assembleur Python écrit `recommendedPath` à chaque run sans filtrer les bloqueurs ; c'est un cas concret du motif « porte unique dans un seul langage » (la règle vit en TypeScript côté écran et côté API à la demande, jamais côté Python qui produit le chemin stocké). Tout consommateur qui lirait `raw_analysis.org.orgGraph.recommendedPath` sans repasser par l'écran (un futur export, le copilote, une API tierce) verrait potentiellement un bloqueur recommandé.
3. **Le badge d'entité (165) ne code pas la couleur par entité** (`variant="outline"` unique) alors que le FINAL et la maquette 02 l'exigent explicitement (« coloré et stable, calculé à partir de l'`entityId` ») — écart mesuré, pas déduit, et déjà noté par `orggraph-contradictions-2026-08-30.md` C7 ; toujours vrai au 30/08 22h (revérifié directement).
4. **Le critère 14 (175) a une moitié non commencée**, et ce n'est pas caché : `orggraph-contradictions-2026-08-30.md` D276 le documente et recommande explicitement de NE PAS dupliquer un second scoring, mais rien ne l'a encore fait entrer dans le scoring du chemin.
5. **L'export PDF (176) n'a jamais eu de section organigramme** — ce n'est pas une régression, c'est un existant jamais couvert ; aucune trace dans le code d'un chantier en cours dessus.

# Audit — Annexe Méthodologie Sales ESN vs code prod (2026-07-22)

Source auditée : `BELLUMAI_ANNEXE_METHODOLOGIE_SALES_ESN_2026-07-21.pdf` (31 p, Théo).
Base de code : `origin/main` @ `5d1be338` (fetch du 22/07).
Méthode : chaque verdict est adossé à une ligne de code lue. Le fil rouge est
**« capturé ≠ consommé »** — un champ capturé mais jamais lu par un prompt/service, ou une
valeur calculée sans consommateur, est compté **NON LIVRÉ**, quoi qu'en dise le plan.

> ⚠️ `agent_docs/methodo-sales-esn-plan.md` marque plusieurs items « FAIT ». Trois d'entre eux
> ne passent pas l'épreuve du consommateur (horizons 7/30/60/90, kanban→relation, `esnRules`).
> Détail plus bas.

## 3. Synthèse — ce que le commercial ne voit pas alors que la maquette le promet

### 3.1 — La contradiction principale entre ce volet et l'audit textuel

L'audit textuel conclut que le critère DoD n°8 (« aucune hiérarchie inventée présentée comme un fait »)
est **le mieux tenu** — « LIVRÉ », le seul des 8. C'est exact **pour le pipeline** : plafond LLM 49,
grounding C → influence, invariant « verified ⇒ sourcé + ≥90 », réparation à l'émission.

**Visuellement, ce critère est violé par le composant le plus regardé de l'écran.** L'arbre React Flow
dessine des traits de reporting calculés par `parentLevel[Math.floor((i * parentLevel.length) /
level.length)]` (`RelationFlow.tsx:120-123`) — de l'arithmétique d'index sur l'ordre de tri — et les
affiche **en trait plein** pour la première rangée (`:136-139`). Le produit garantit dans son JSON qu'il
n'invente pas de hiérarchie, et en dessine une à l'écran. Aucune des deux briques n'est fausse
isolément : c'est le **branchement entre les deux qui n'existe pas**.

## Qui signe la recette d'une migration de routes (DEC-4036 Q1, décision Louis 19/10/2026, #2958.106-.109)

**Louis SEUL signe** la recette d'une migration de routes (passage NO-GO → GO d'une route du registre, retrait d'une
redirection, fin de coexistence). Les recettes métier des bêta-testeurs (#2958.106 Antoine, #2958.107 Hervé, #2958.108
recette recruteur, #2958.109) restent des **retours** : elles ouvrent des cases, elles ne valent pas signature. Un agent
ne signe jamais — il rapporte un verdict (PASS / FAIL / PARTIAL / BLOCKED) que Louis contresigne ou non. Règle de
gouvernance, aucun code : rien ne la garde par un test, elle tient par cette ligne et par la relecture.
